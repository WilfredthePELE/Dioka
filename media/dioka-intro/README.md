# Dioka white-studio introduction

Editable HyperFrames composition for the website's silent six-second 1280×720, 24fps intro. The portrait was generated with OpenAI ImageGen on 20 October 2026. It depicts a fictional mature shoemaker, not a photographed member of the Dioka team. The loop animates a camera move over this portrait; it does not synthesize live-action hand movement.

The website overlays only DIOKA in emerald green and an icon-only entry control. Keep the film text-free so the wordmark stays readable on mobile. Rebuild with the pinned scripts in package.json; lint/runtime/layout checks should pass first. The matching website assets are public/dioka-white-studio-shoemaker.png and public/dioka-white-studio-loop.mp4.
